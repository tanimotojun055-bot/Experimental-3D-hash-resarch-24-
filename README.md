# Experimental-3D-hash-resarch-24-
24分岐探索の導入
3DH-v1 24分岐実験（2026-10-11）
=====================================

目的
  2026-10-08に公開された 3DH-v1 Candidate A の3D-MIX64を踏襲し、
  6方向（+X,-X,+Y,-Y,+Z,-Z）から深さ順序を保って全層を2Dに投影、
  各面を4つの象限（Q0..Q3）に分ける試験コードを追加しました。
  6面×4象限＝24分岐です。

重要事項
  旧コードの3D-MIX64は引き継いでいますが、面への射影畳み込み式は
  この実験で新しく追加した暫定式です。正式仕様として確定していません。
  512bit内部状態と最終256bitダイジェストは未実装です。
  暗号としての安全性・原像耐性・衝突耐性は未証明です。

Termuxでの実行
  pkg install python
  pip install numpy
  python 3dh_24branch_experiment.py

基本実験（高速）
  python 3dh_24branch_experiment.py --n 8 --rounds 6 --mode both

前回のLIGHT相当で6面24分岐の変化量を確認（こちらは時間がかかる）
  python 3dh_24branch_experiment.py --n 64 --rounds 64 --mode diffusion

  モード 'axes': X、Y、Zの各方向へ入力位置を1セルずらし、24分岐とSHA-256の差分を比較。
       移動は入力グリッド上の2ビット差です。256ビットの3DH出力との比較ではありません。
  モード 'diffusion': 1bitの差による24分岐の変化量を計測します。
  モード 'search': 1bitの入力位置が未知という玩具モデルを総当たりし、
       同じ候補集合についてSHA-256と試行回数・時間を比較します。
       n<=12に制限。既存の3DHハッシュの解読ではありません。
       攻撃者に24の中間データが見える、わざと簡略化した実験です。

評価の注意
  旧報告のスマホ約6.34秒は64x64x64・64ラウンドでの2状態拡散実験。
  今回は6面投影の処理が増え、同じ計算時間ではありません。
  24分岐を持つことから攻撃に24^k回かかるとは推論できません。
  SHA-256より一兆倍解読困難、という主張を検証した結果ではありません。
  SHA-256への比較は「同じ単純な候補探索に対する計算コスト」のみです。
  本当の比較には完成した256bit 3DH 出力、攻撃モデル、解析が必要です。
